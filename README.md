## How I approach engineering

- **Correctness first:** use idempotency, database constraints, and conditional updates to make failure cases explicit.
- **Security by design:** validate inputs, restrict data access, apply allow-lists, and add rate limits around user input and LLM workflows.
- **Scale deliberately:** favor stateless services, Pub/Sub fan-out, and recoverable synchronization over fragile session dependencies.
- **Keep it maintainable:** choose the simplest design that meets the reliability and product requirements.
